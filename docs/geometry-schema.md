# Geometry schema

Files:
- `assets/geometry/schema/geometry.schema.json` — JSON Schema 2020-12 for calibrated plan geometry.
- `assets/geometry/schema/apartments.schema.json` — apartment inventory.
- Validator: `scripts/validate/validate_geometry.py` (schema + naming + closure + area + units + calibration gate).

## Conventions
- Units: metres (`"units": "m"`). Calibrated from the source only.
- Coordinates: origin = south-west corner of the drawn envelope; X east, Y north, Z up. Polygons are rings of `[x, y]` (first == last).
- North: `coordinate_system.north_arrow_deg` is null and `north_arrow_source` is `"UNKNOWN"` unless the drawing shows an arrow.
- Object ids: `{BUILDING}__{LEVEL}__{UNIT}__{TYPE}__{INDEX}`, e.g. `B01__L00__U001__wall__001`.
  - Unit ids have no TYPE: `B01__L00__U001` (or `…__NONE`).
  - TYPE ∈ wall | slab | window | door | balcony | stair | column | roof | site.
- Flags vocabulary: MISSING_SOURCE, UNKNOWN, UNCALIBRATED, HEIGHT_UNKNOWN, ROOM_NAME_UNKNOWN, OPENINGS_UNKNOWN, AMBIGUOUS, SYNTHETIC, RESIDUAL_OVER_2PCT, SCALE_MISMATCH, NO_DIMENSIONS, DIM_NO_SEGMENT, NORTH_UNKNOWN.

## Top-level fields
| Field | Meaning |
|---|---|
| `project` | `{name, id, is_real_project}` — synthetic fixtures set `is_real_project: false` |
| `source` | `{file, sha256, page, provenance, source_url?, retrieved_at?}`; `sha256` is `SET_BY_RUNNER` only in config |
| `calibration` | `{method, scale_denominator, metres_per_pt, residual, uncalibrated}`; when uncalibrated, metres_per_pt is null |
| `buildings[]` → `levels[]` → `units[]` | hierarchy; level id `L00`, `L01`… or `LM01`… |
| `unit` | `{id, label, polygon_m|null, area_m2|null, rooms[], walls[], openings[], confidence, flags[]}` |
| `room` | `{name, polygon_m, area_m2, confidence, flags[]}` |
| `wall` | `{id, semantic_id, start_m, end_m, thickness_m, height_m|null, confidence, flags[]}` |
| `opening` | `{id, type: window|door, wall_id, width_m|null, sill_height_m|null, height_m|null, confidence, flags[]}` |
| `missing[]` | plain-language list of every unknown the output depends on |

## Apartment inventory (`apartments.json`)
Each unit: `unit_id` (source label, e.g. `H 0.1`), `building`, `level`, `unit_type` (2-room…5-room mapped from Dvosoban…Peterosoban), `unit_type_source_label`, `net_area_m2` (null), `gross_area_m2` (listing value), `orientation` (null), `status` (Slobodno|Prodano), `property_type`, `source_ref` (detail URL), `flags`. No price fields (none sourced). Flags: AREA_NET_UNVERIFIED, AREA_GROSS_UNVERIFIED, AREA_BASIS_NOT_CONFIRMED, ORIENTATION_UNKNOWN, PLAN_NOT_VECTOR, MISSING_SOURCE, UNKNOWN.
